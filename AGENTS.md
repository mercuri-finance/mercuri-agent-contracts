# Separate Mercurifi Agent Accounts contracts repository — Codex

This public Git repository owns the Mercurifi Agent Accounts contracts, apart from Launch's and Trade's contract sets: source, tests, release tooling, deployment inputs and the deployment records. In the Mercurifi workspace it lives at `contracts/agents`. Launch's deployed contracts are the pinned submodule `lib/mercuri-launch-contracts`; never change them here, and flag any need for them to the owner as a live-contract change. Only Arc testnet is deployed (`deployments/5042002.json`); mainnet needs its own release authorization. The release evidence is `docs/agent-accounts.md`, section 10. Run `bash script/check-contracts.sh` for a candidate change, and keep every `lib/` submodule at its recorded pin (`lib-versions.md`); the Universal Router closure must match `script/universal-router/source-manifest.json`. Before any commit, push, PR or issue, follow the identity gate in `../../docs/agents/release.md`: login, author, committer and HTTPS push transport must all be `mercurifinance`, with no AI `Co-authored-by` trailer. Keep the repository public-clean: no personal or company names, local paths, private repository names, internal hosts or keys. Local builds and tests do not authorize a broadcast, governance action or deployment record. Never read `.env` or disclose signer material. The workspace `.agents/skills/mercuri-contract-assurance/` provides the review path.
